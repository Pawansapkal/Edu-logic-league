# EdQuest - Gamified Learning for Class 10

EdQuest is a gamified education platform built for Class 10 students to make exam preparation interactive and rewarding. Instead of boring mock tests, students complete "Challenges," earn XP, and track their progress on a dynamic dashboard.

## Tech Stack
* **Frontend:** HTML, Tailwind CSS (for sleek gamified UI), Vanilla JS, Chart.js
* **Backend:** Python, Flask, SQLite
* **Features:** XP progression system, interactive arena, progress tracking.

## How to Run Locally
1. Navigate to the `backend` folder: `cd backend`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the server: `python app.py` (Runs on http://localhost:5000)
4. Open `frontend/index.html` in your web browser to start the app!
